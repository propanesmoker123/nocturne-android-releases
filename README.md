# Nocturne для Android

Здесь лежат готовые установщики (APK) Nocturne — плеера VK Музыки для Android.

## Как поставить

1. Откройте [последний выпуск](https://github.com/propanesmoker123/nocturne-android-releases/releases/latest) с телефона и скачайте `Nocturne-<версия>.apk`.
2. Откройте файл и разрешите установку из этого источника, если телефон спросит.
3. Откройте Nocturne и войдите через VK — на странице самого VK (Nocturne пароль не видит).

Новые версии приложение находит само: в «Ещё» и в настройках появится «Обновить».

Нужен Android 7.0 или новее.

Неофициальный клиент. Nocturne не связан с VK.
